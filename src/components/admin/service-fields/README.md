Service settings edit independent page/navbar visibility, navbar copy/group/order, and all seeded structured page sections. Each artwork slot accepts an uploaded image/video or an existing URL. Media uploads use the authenticated R2 endpoint. The shared content editor owns saving, permissions, FAQ and SEO editing, optimistic version checks, and AI proposal review.

All six slots now use `ServiceVisualField` to select an image, shader, default illustration or legacy image/video editor. Reviewed shader definitions drive bounded controls and local previews; the backend catalog confirms matching contracts before Save. Section images use verified `service_image` assets. Shaders need only their settings and description, without a fallback upload; any existing poster metadata remains accepted. The old media editor remains for existing media and deliberate rollback. `fields.visuals` overrides, but does not delete, the old `fields.media` choice. See `components/shaders/README.md`.

Global shader activation lives separately at **Admin → Shaders** (`/admin/shaders`) in the sidebar. This form links to that page but does not activate or deactivate library entries. Catalog errors show the backend's safe diagnostic and a retry action.
