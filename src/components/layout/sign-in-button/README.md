# Sign-in button

Standalone fixed top-right link to `/login`, rendered beside (not inside) the navbar. Frosted glass, an accent-lit indicator and a short reflective hover sweep share the global accent tokens. Keyboard focus gets the same treatment; reduced motion disables movement. Navigation reserves horizontal space for it on desktop and mobile.

The compact rectangular button keeps a 44px minimum target height. Its desktop right inset scales from 32px to 72px, placing it farther left; tablet and phone insets are 24px and 18px respectively.
