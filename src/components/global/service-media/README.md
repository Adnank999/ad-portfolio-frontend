`ServiceMedia` displays an uploaded service image or a video with native controls, an accessible description and an optional poster/caption. The existing artwork is the fallback for empty media slots. Media is never autoplayed.

An optional tagged `visual` takes precedence over legacy media. It delegates images/shaders to `components/visuals/VisualRenderer`; shader-capable slots must share `ActiveShaderProvider`. Pass `eager` for hero image loading. The service page wires this for all six slots, keeping one WebGL renderer active through fade-in/out handoffs and a plain page-colored background elsewhere. Shader posters are not displayed or required. Hero shaders use a full-section background layer; image/video layouts are unchanged. See `components/shaders/README.md` for authoring and deployment.
