# Editorial accordion

Shared FAQ rows for services, case studies, industry pages and articles. Uses the About challenge section's numbered editorial headings, fine rules and plus/minus icons. Answers and questions are passed through unchanged. One answer opens at a time; triggers expose their state and associated region, work with native keyboard buttons and retain visible focus. Pass `light` on paper-colored pages, or `initialOpen={0}` for the service method's first step. Closed answers remain in server HTML for indexing and become available to assistive technology when expanded.
